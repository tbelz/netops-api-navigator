## Highlights

- Adds an authenticated localhost Streamable HTTP service so concurrent MCP
  clients can share one persistent graph owner. STDIO remains the default.
- Restores fresh FTS/algo installation by pinning the official `ladybug==0.17.1`
  distribution, with compiler parser compatibility and fresh-cache checks.
- Preserves corruption diagnostics and improves graph-lock guidance.

## Upgrade notes

**Back up before upgrading:** the new engine upgrades storage format 40 to 41
on its first writable open, including startup or `doctor`. Stop the old graph
owner cleanly and preserve the complete consistent graph directory, manifests
and sidecars before starting 0.3.2. The old engine cannot read an upgraded graph;
rollback requires restoring the entire pre-upgrade backup. See the
[deployment and rollback procedure](https://github.com/tbelz/netops-api-navigator/blob/v0.3.2/docs/ladybug-extension-upgrade.md).
